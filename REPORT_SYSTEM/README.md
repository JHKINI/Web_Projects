# 실험 기록 웹 시스템



## 📌 프로젝트 소개

실험 데이터를 입력, 저장하고 분석할 수 있는 웹 기반 시스템입니다.



## 💡 주요 기능

- 실험 데이터 입력 및 저장 (localStorage)

- 날짜별 검색 기능

- 데이터 삭제 기능

- 평균값 계산

- Chart.js를 이용한 그래프 시각화

- CSV(엑셀) 다운로드 기능



## 🛠 사용 기술

- HTML

- JavaScript

- Chart.js



## 📊 실행 방법

index.html 파일을 브라우저에서 실행
